# CodeBoard Web

## Описание
CodeBoard Web — это веб-приложение платформы CodeBoard, предназначенной для публикации, просмотра и взаимодействия с программным кодом.

## Технологии
- React + TypeScript
- Vite
- Tailwind CSS v4
- Axios
- React Router

## Основной функционал
- Просмотр ленты постов
- Просмотр отдельного поста с кодом
- Поиск постов и фильтрация по тегам
- Авторизация и регистрация
- Создание и редактирование постов
- Лайки и комментарии
- Профиль пользователя

## Архитектура
- Компонентный подход (React)
- Разделение на страницы и переиспользуемые компоненты
- API-интеграция через Axios

## Установка и запуск
```bash
npm install
npm run dev
```

## Переменные окружения
Создать файл .env:
```
VITE_API_URL=http://localhost:3000/api
```

## Особенности
- Используется PrismJS для подсветки кода
- Адаптивная сетка (masonry)
